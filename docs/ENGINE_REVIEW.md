## VFR 수정과 검증

기존에는 출력 시각에 명목 FPS 간격의 0.45배를 더했다. 불규칙한 간격에서는 최근접 프레임을 보장하지 않는다. 새 검사는 14개 샘플 사이 간격이 10ms에서 630ms까지 달라지는 2.6초 영상을 만든다. 수정 전 H.264→GIF 첫 출력은 요청 시각 0.35초에서 0.42초 프레임을 골랐지만, 가장 가까운 프레임은 0.41초였다.

정확한 샘플 커서를 제공하는 단일 미디어 구간 파일에서는 [AVSampleCursor](https://developer.apple.com/documentation/avfoundation/avsamplecursor)로 앞뒤의 실제 PTS를 비교한다. 커서 시각은 컨테이너 편집 매핑을 통해 재생 시각으로 바꾼다. B-frame 선행 구간 때문에 이 매핑을 생략하면 잘못된 프레임을 고를 수 있다. 같은 원본 프레임은 한 번만 추출한다. 프레임 전체를 먼저 디코딩하거나 타임스탬프 배열을 무제한 저장하지 않는다.

검사 기준은 `AVAssetReader`로 순차 디코딩한 실제 PTS와 픽셀이다. H.264/HEVC/ProRes 각각 GIF/WebP의 모든 출력 프레임을 비교한다. GIF의 누적 10ms 양자화와 WebP의 동일 프레임 병합을 고려하며, 원본 해시와 실패 시 출력 정리도 검사한다. 기존 15/24/30/60fps, 회전, 12ms 오프셋, 목표 용량, 취소 검사도 유지한다.

정밀 커서가 없거나 여러 미디어 편집 구간으로 구성된 파일은 기존 FPS 보정 경로를 유지한다. 이 경로까지 불규칙 VFR의 최근접 선택을 보장하지 않는다. 장시간 실사·HDR·다양한 VFR 편집 목록 전체를 검증한 결과도 아니다.

```sh
Tools/test-vfr.sh
Tools/test-animation.sh
Tools/test-animated-images.sh /path/to/animated.webp
Tools/benchmark-engine-resources.sh
```

## 원본 GIF/WebP 편집

확장자 대신 실제 프레임 수로 정지 이미지와 움짤을 구분한다. 움짤은 명시적 재생/일시정지, 프레임 이동, 전체 프레임 자르기·크기 조절, 선택 프레임 PNG 저장을 제공한다. 처음에는 미리보기를 정지하고, 창이 닫히거나 앱이 비활성화되면 재생을 멈춘다.

전체 움짤 편집 결과는 무손실 WebP다. GIF의 기존 팔레트 한계를 복원하지는 않지만 GIF 재인코딩에 따른 추가 팔레트 손실을 피한다. 자르기는 픽셀을 그대로 유지하며, 크기 조절은 고품질 리샘플링 결과를 저장한다. 지연·반복·투명도·색 공간과 모든 프레임의 저장 픽셀을 검사한 뒤 새 파일로 게시한다. GIF 재저장, APNG, 영상 오디오 보존은 이 편집 기능의 지원 범위가 아니다.

사용자가 제공한 1080×608, 440프레임 WebP를 자른 결과는 별도 Pillow/libwebp 디코더에서도 모든 RGBA 픽셀, 지연과 반복 정보가 일치했다. 사용자 입력 파일과 GUI 검증 산출물은 저장소나 릴리즈에 포함하지 않는다.

## 0.2.8 움짤 UI 보완

프레임 슬라이더는 눈금 없는 연속 컨트롤로 바꾸되 선택 값은 프레임 인덱스로 맞추고, 이전·다음 프레임 버튼을 유지한다. 자르기 미리보기는 사각형 캔버스에 사각형 자르기 프레임을 표시해 바깥 모서리에 잘리지 않게 한다. 실제 저장 영역도 계속 사각형이다.

이미 움직이는 WebP인 경우 중복 WebP 변환 대신 재생 속도를 제공한다. 0.25~4배에서 재압축 없이 WebP의 ANMF 시간 필드만 바꾼다. 프레임 생략 없이 누적 지연을 밀리초 단위로 양자화하며, 모든 프레임의 픽셀·투명도·반복 정보를 확인한 후 무손실 WebP로 게시한다. GIF의 WebP 변환은 유지한다.

‘한 장 저장’은 중앙으로 접힌 뒤 PNG/JPG/WebP 포맷 링을 펼친다. 포맷을 고르면 해당 프레임 선택 화면으로 이동한다. 취소는 포맷 링으로, 뒤로/esc는 원래 메뉴로 돌아간다. 전환 도중 중복 입력을 막고 동작 줄이기를 반영한다. PNG/WebP는 무손실이며 JPG는 최고 품질 손실 압축·흰 배경 합성을 명시한다.

검증: 네이티브 화면에서 흡수/펼침, 포맷 선택·취소·키보드 이동, 눈금 제거와 사각 자르기 캔버스를 확인했다. `Tools/test-animated-images.sh`는 세 정지 포맷의 선택 프레임·투명도 정책, 0.5/1.5/2배의 누적 시간·모든 픽셀·반복 보존, 기존 편집과 실패 시 정리를 검사한다.
